Dominant-color extraction — k-means (k=3), from scratch

A static-image test harness for the clustering step, fully decoupled from the camera. Pixels are read from a <canvas> via getImageData(), downsampled, then clustered by hand-written k-means so the algorithm can be debugged without live-video noise.

Known limitation (by design for v1): distance is plain RGB Euclidean, which is not perceptually uniform — two colors that look equally different to the eye can be near or far in RGB space. A perceptual space (CIELAB + CIEDE2000) would rank more like human vision, but is out of scope here. Note too that cluster size ranks by pixel count, so a small but vivid accent legitimately lands last — visual prominence ≠ area.
